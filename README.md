Movix - Movie Discovery App
A modern and responsive movie discovery web application built using React and Vite. It allows users to explore trending movies, search in real time, and view detailed movie information through a clean cinematic interface.

Features
* Real time search with debouncing for better performance
* Trending movies section
* Dynamic movie listings
* Ratings, language, and release year details
* Fast loading with spinner
* Modern UI with glassmorphism and glow effects
* Fully responsive design 

Tech Stack
* React
* Vite
* Tailwind CSS
* TMDB API
* Appwrite
* React Hooks
* Debouncing with react-use

UI Highlights
* Cinematic background with gradient overlays
* Smooth hover animations and glow effects
* Glassmorphism search bar
* Responsive movie cards layout
