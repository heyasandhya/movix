🚀 Movix – Movie Discovery App

A modern and responsive movie discovery web application built using React + Vite, allowing users to explore trending movies, search in real-time, and view detailed movie information with a clean cinematic UI.

🎬 Features
🔍 Real-time Search (Debounced for performance)
🔥 Trending Movies Section
🎯 Dynamic Movie Listings
⭐ Ratings, Language & Release Year
⚡ Fast Loading with Spinner
🎨 Modern UI with Glassmorphism & Glow Effects
📱 Fully Responsive Design


🛠️ Tech Stack
⚛️ React.js
⚡ Vite
🎨 Tailwind CSS
🎬 TMDB API
🧠 Appwrite (for trending/search tracking)
🔁 React Hooks (useState, useEffect)
⏳ Debouncing (react-use)


🎨 UI Highlights
Cinematic background with gradient overlays 🎬
Glow effects & smooth hover animations ✨
Glassmorphism search bar 🔍
Clean movie cards with responsive grid
